Konfigurasi Kredensial & Pemasangan di GitHub Pages

Kredensial API Supabase Anon Public Key aman ditanam langsung di GitHub karena dilindungi oleh Row Level Security (RLS) di database PostgreSQL.

Cara Pasang Permanen di GitHub Pages (Gratis & Online Selamanya):
  1. Masukkan Project URL dan Anon Key pada kolom di atas.
  2. Klik tombol "Unduh index.html untuk GitHub (Kredensial Tertanam)" di bawah ini.
  3. Buka akun GitHub.com, buat repositori baru (misal: absensi-mtsn3).
  4. Unggah file index.html yang baru saja Anda unduh ke repositori tersebut.
  5. Masuk ke tab Settings → Pages di repositori GitHub, pada bagian Branch pilih main lalu klik Save.
  6. Selesai! Aplikasi absensi Anda dapat diakses secara online di URL: https://username.github.io/absensi-mtsn3/
